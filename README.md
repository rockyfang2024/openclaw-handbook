# AI 助手搭建手册

> 让小白也能快速上手 AI 助手的中文操作手册。

**两大方案：OpenClaw vs Hermes**

***

## 🤖 选择你的学习路径

### [→ OpenClaw 教程](README-OPENCLAW.md)

**适合：快速搭建个人 AI 助手**

- 腾讯云服务器 + OpenClaw + 飞书
- 七章学习路径：服务器 → 模型 → 飞书 → 定时任务 → Skill → 多Agent → 场景案例
- 成熟方案，社区活跃

***

### [→ Hermes 教程](README-HERMES.md)

**适合：进阶用户，自定义 Agent 矩阵**

- 多 Agent 协作系统（角色分工：私人助理、投资教练、英语导师...）
- 支持飞书等多平台接入
- 更灵活的能力配置

***

## 📊 两套方案对比

| | OpenClaw | Hermes |
|--|--|--|
| 定位 | 个人 AI 助手 | Agent 矩阵系统 |
| 多 Agent | 单 Agent | 多 Agent 协作 |
| 复杂度 | 入门简单 | 配置灵活 |
| 平台 | 飞书为主 | 飞书 + 多平台 |
| 学习曲线 | 平缓 | 稍陡 |
